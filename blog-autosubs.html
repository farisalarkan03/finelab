Sepenuhnya Gratis & Open Source

Autosubs dirilis di bawah lisensi MIT — bebas digunakan untuk proyek pribadi maupun komersial, bebas dimodifikasi, dan bebas didistribusikan ulang. Tidak ada biaya berlangganan, tidak ada watermark, tidak ada batasan.

Apa Itu Autosubs?

Autosubs (nama resmi repositori: auto-subs) adalah sebuah script / plugin gratis untuk DaVinci Resolve yang mengotomatiskan pembuatan subtitle menggunakan teknologi kecerdasan buatan. Plugin ini memanfaatkan model transkripsi OpenAI Whisper — salah satu model speech-to-text terbaik di dunia — untuk mendengarkan audio di timeline kamu dan secara otomatis menghasilkan teks subtitle yang presisi, kemudian langsung meletakkannya sebagai Text+ nodes di atas klip video.

Sebelum adanya Autosubs, seorang video editor harus mengetik subtitle secara manual kata per kata, mengatur timing dengan seksama, dan memastikan sinkronisasi sempurna dengan audio — sebuah pekerjaan yang bisa memakan waktu berjam-jam bahkan untuk video berdurasi 10 menit. Autosubs memotong proses itu menjadi hanya beberapa klik.

Plugin ini sangat cocok untuk YouTuber, podcaster, filmmaker, content creator, maupun editor profesional yang ingin menghemat waktu tanpa mengorbankan kualitas hasil subtitle. Karena berjalan sepenuhnya secara lokal di komputermu, privasi audiomu pun terjaga sepenuhnya.

Persyaratan Sistem

Autosubs membutuhkan DaVinci Resolve 18 atau lebih baru (Free maupun Studio sama-sama didukung), Python 3.8+, dan koneksi internet hanya saat pertama kali mengunduh model Whisper. Setelah itu bekerja sepenuhnya offline tanpa koneksi apapun.

Langkah 1 — Ekstraksi Audio: Plugin memanggil API resmi DaVinci Resolve untuk mengekstrak audio dari timeline yang sedang aktif, menghasilkan file audio sementara di lokal.

Langkah 2 — Transkripsi Whisper: Audio dikirim ke model Whisper yang berjalan secara lokal. Whisper memproses audio, memotongnya menjadi segmen-segmen berdasarkan jeda bicara, lalu mengkonversi setiap segmen menjadi teks dengan timestamp awal dan akhir yang presisi dalam hitungan detik.

Langkah 3 — Pembangkitan Subtitle: Setiap pasangan teks-timestamp dikonversi menjadi sebuah Text+ node di timeline DaVinci Resolve. Node ditempatkan di track khusus tepat sesuai timing audio aslinya — tidak ada yang perlu kamu sesuaikan secara manual.

Langkah 4 — Penerapan Template: Jika kamu telah mendefinisikan template subtitle khusus di DaVinci Resolve, Autosubs akan menerapkan styling tersebut ke semua node yang dibuat secara konsisten — font, warna, ukuran, dan posisi terjaga seragam dari awal hingga akhir video.

Cara Instalasi Autosubs

Proses instalasi Autosubs dirancang sesederhana mungkin. Ikuti langkah-langkah berikut dan kamu bisa mulai menggunakannya dalam hitungan menit.

1

Pastikan Python Sudah Terinstall

Autosubs membutuhkan Python 3.8 atau lebih baru. Download gratis di python.org. Saat instalasi di Windows, pastikan opsi "Add Python to PATH" dicentang. Verifikasi instalasi dengan perintah berikut:

python --version
2

Download Autosubs dari GitHub

Kunjungi repositori resmi di github.com/tmoroney/auto-subs. Klik tombol hijau "Code" lalu pilih "Download ZIP". Atau gunakan Git untuk clone repositori:

git clone https://github.com/tmoroney/auto-subs.git
3

Install Semua Dependensi

Buka terminal / command prompt di folder Autosubs yang sudah di-download, lalu jalankan perintah berikut untuk menginstall semua library yang dibutuhkan, termasuk OpenAI Whisper dan ffmpeg-python:

pip install -r requirements.txt
4

Salin Script ke Folder DaVinci Resolve

Salin folder/file script Autosubs ke direktori script DaVinci Resolve. Lokasi berbeda per sistem operasi:

Windows: %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility
Mac: ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility
Linux: ~/.local/share/DaVinciResolve/Fusion/Scripts/Utility
5

Jalankan dari DaVinci Resolve

Buka DaVinci Resolve, buka project dan timeline yang ingin diberi subtitle, lalu masuk ke menu Workspace → Scripts → Utility → Autosubs. Panel Autosubs akan muncul. Pilih bahasa, pilih ukuran model, lalu klik Generate Subtitles — selesai!

rocket_launch
Tips: Pilih Ukuran Model yang Tepat

Untuk komputer dengan RAM terbatas (8GB ke bawah), gunakan model base atau small untuk hasil cepat. Untuk akurasi maksimal di komputer bertenaga tinggi (16GB RAM+, GPU Nvidia), gunakan model large-v3. Model medium adalah titik tengah terbaik untuk kebanyakan pengguna. Model hanya perlu diunduh sekali — setelahnya berjalan offline sepenuhnya.
