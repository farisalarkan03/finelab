Autosubs —
Plugin Subtitle Gratis untuk DaVinci Resolve

Buat subtitle otomatis berakurasi tinggi langsung di timeline DaVinci Resolve dengan AI OpenAI Whisper. Tanpa biaya langganan, tanpa upload cloud, dan 100% open-source.

Download di GitHub menu_book Panduan Install

Kenapa Menggunakan Autosubs?

Mengetik dan menyesuaikan subtitle manual seringkali memakan waktu berjam-jam. Autosubs (karya Tiernan Moroney) memanfaatkan model pengenal suara AI OpenAI Whisper untuk mentranskripsi audio langsung menjadi node Text+ di DaVinci Resolve.

bolt Selesai Hitungan Menit Deteksi otomatis jeda bicara dan timestamp audio secara instan.
lock 100% Offline & Aman File audio Anda tidak pernah dikirim ke cloud. Privasi proyek tetap terjaga.
translate Bahasa Indonesia & 90+ Lainnya Mendukung multi-bahasa dengan akurasi pengenalan kata yang tinggi.
tune Format Native Text+ Font, warna, animasi, dan posisi teks tetap bisa dikustomisasi sesuka hati.

Panduan Instalasi Mudah

Pilih sistem operasi yang Anda gunakan untuk setup cepat dalam beberapa langkah:

laptop_mac Instalasi macOS (Paling Praktis via Homebrew)
macOS
1
Pasang Python & FFmpeg via Homebrew Buka aplikasi Terminal di Mac Anda, lalu jalankan perintah ini:
brew install python ffmpeg
2
Download Autosubs & Install Dependensi Unduh repositori dan pasang library Whisper dengan dua baris perintah ini:
git clone https://github.com/tmoroney/auto-subs.git && cd auto-subs
pip3 install -r requirements.txt
3
Salin Script ke Folder DaVinci Resolve Pindahkan folder script ke direktori DaVinci Resolve dengan perintah terminal ini:
cp -r . ~/Library/Application\ Support/Blackmagic\ Design/DaVinci\ Resolve/Fusion/Scripts/Utility/auto-subs
Atau buka Finder → Go to Folder (Cmd + Shift + G) lalu paste path di atas dan drag folder auto-subs ke dalamnya.
desktop_windows Instalasi Windows (Mudah via Winget / CMD)
Windows
1
Pasang Python & FFmpeg Buka Command Prompt (CMD) atau PowerShell, lalu jalankan perintah winget:
winget install Python.Python.3.11 Gyan.FFmpeg
Atau download installer manual di python.org (pastikan centang opsi "Add Python to PATH").
2
Download Autosubs & Install Dependensi Download ZIP dari GitHub Autosubs & ekstrak. Buka terminal di folder tersebut lalu jalankan:
pip install -r requirements.txt
3
Salin ke Folder Scripts Resolve Tekan Win + R, ketik path ini dan tekan Enter:
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility
Salin folder Autosubs ke dalam folder tersebut.
play_circle Cara Menjalankan di DaVinci Resolve

1. Buka DaVinci Resolve dan timeline proyek video Anda.
2. Masuk ke menu bar atas: Workspace → Scripts → Utility → Autosubs.
3. Dialog Autosubs akan muncul. Pilih bahasa (misal: Indonesian), pilih ukuran model Whisper, lalu tekan tombol Generate Subtitles. Selesai! Subtitle Text+ otomatis masuk rapi di timeline.

rocket_launch
Tips Memilih Model Whisper

Saat menjalankan Autosubs, Anda dapat memilih ukuran model AI yang sesuai dengan spek laptop/PC:

  • check_circle Base / Small: Pilihan super cepat untuk laptop tipis / RAM ≤ 8 GB.
  • check_circle Medium (Paling Pas): Titik seimbang terbaik antara akurasi tinggi dan render cepat untuk konten video harian.
  • check_circle Large-v3: Akurasi maksimal untuk rekaman cepat / musik bising (disarankan jika memiliki GPU NVIDIA ≥ 16 GB RAM).

*Model hanya didownload sekali di awal, selanjutnya bekerja 100% offline.
